# F4-11 — контроль сохранности STEP-тела

Проверка выполнена на исходном `F4-11.stp`, интерпретируя его единственное тело `SOLID` как **сохраняемую деталь**, а не как заготовку. Контуры в `GEOMETRIC_CURVE_SET` используются как траектории горячей струны.

Использован OpenCascade (`BRepClass3d_SolidClassifier`), геометрия B-spline считана непосредственно из STEP; начало/обход согласованы по центрированной форме. Для каждой пары взято 33 положения вдоль траектории (параметры 0, 4/128, ..., 1) и девять внутренних отсчётов по длине прямой струны между профилями. Итого 297 проверенных точек на операцию. Допуск классификатора — 0.0001 мм.

| Операция | Направляющие | Положений проверено | Точек строго внутри сохраняемого тела | На поверхности |
|---|---|---:|---:|---:|
| B0 | #197 / #544 | 297 | **125** | 60 |
| B90 | #337 / #681 | 297 | **51** | 21 |

- B0: прямая синхронизация, фазовый сдвиг 0, среднее расхождение форм 0 мм.
- B90: прямой обход, сдвиг приблизительно 127/128, RMS ~9.38 мм.
- Проверка строго классифицирует часть точек струны **внутри исходного STEP-тела**, а не просто внутри прямоугольной заготовки. Если это тело является готовой деталью, текущие проходы её нарушают.
- Это дискретная проверка: доли промежуточных пересечений она может не обнаружить. Наличие внутренних попаданий является достаточным основанием не разрешать резку; отсутствие попаданий не является сертификатом безопасности.
- Воксельная симуляция по B0/B90 учитывает последовательное удаление прорези и торцевание, но пока не классифицирует **какие именно** воксели относятся к детальной поверхности STEP. При шаге 5 мм и `stock=100×300×180` мм, `bottomZ=5` мм, торцевание B0 снимает 5760 вокселей. После B0 затем B90 остаётся 27274, и после B90 затем B0 — тоже 27274; **промежуточные** состояния и входы/выходы различаются.

## Как повторить контроль по своему диагностическому экспорту

1. В Foam Wire Cutter выберите пары в 3D, проверьте входы/выходы, затем нажмите **«Экспорт траектории (диагностика)»**.
2. Убедитесь, что STEP не повёрнут и масштаб равен 100%, затем выполните:
   ```sh
   python -m pip install cadquery
   python tools/verify_f4_solid.py F4-11.stp F4-11-motion-DIAGNOSTIC.json --output F4-11-solid-check.json
   ```
3. Отчёт покажет `confirmed_inside_solid` отдельно для каждой операции. Любое значение больше нуля означает подтверждённую геометрическую проблему, **если STEP-solid — сохраняемая деталь**.

### Неразрешённые условия станочного кода

- Требуется либо изменить соответствие направляющих/их геометрию, либо подтвердить, что STEP SOLID обозначает *не* сохраняемый объём.
- Отдельно подтвердить правильное положение B90, сторону припуска от реза, допуск горячей струны и отсутствие провисания.
- Провести полную проверку объёма, снятого после каждого шага, и режущих входов в отход, включая фиксацию детали.
- До этого `approvedForGcode=false` — **отправлять диагностический JSON на станок нельзя**.
