# Струнная резка пенопласта

Программа для станка с горячей струной и поворотным столом (GRBL, оси XYZAB).

> ⚠️ **Аварийная остановка — только физическим ключом или выключателем питания.** Кнопка «Стоп» на странице не является аварийной.

## Возможности

- **Вкладка «ГЕНЕРАТОР G-CODE»** строит G-код из STEP-файла:
  1. одна деталь;
  2. две детали из одной заготовки, одна из них зеркальная (например, левая и правая консоли крыла).
- **Вкладка «РЕЗКА»** показывает программу в 3D, отправляет её на станок и управляет им по USB.

## Запуск

### Веб-страница

Откройте `index.html` в браузере: установка не нужна, интернет тоже. Управление станком по USB работает только в Chrome или Edge: страница открывает COM-порт через Web Serial.

Папка `lib/` (three.js r128, лицензия MIT — `lib/three.LICENSE`) нужна для 3D-вида, держите её рядом с `index.html`.

### Python-генератор

Резервный вариант без браузера. Нужен Python 3, сторонние пакеты не требуются.

```
python FM_step2gcode.py деталь.stp --stock 340 230 50 --bottom-z 10
```

G-код сохраняется рядом с STEP-файлом под именем `деталь_auto.gcode` (или в файл из `-o`).

| Параметр | Что задаёт | По умолчанию |
|---|---|---|
| `--stock ДЛИНА ШИРИНА ТОЛЩИНА` | заготовка, мм: вдоль размаха, вдоль хорды, толщина | `340 230 50` |
| `--bottom-z` | Z нижней грани заготовки, мм | `10` |
| `--material` | пенопласт из `materials.json` | `_default` из файла |
| `--kerf` | толщина реза, мм (`0` — без компенсации) | из материала |
| `--lead-side {+,-}` | сторона входа в контур по Y каретки | `+` |
| `--lead-margin` | вынос входа за край заготовки, мм | `5` |
| `--retract` | отвод при торцевании, мм | `30` |
| `--sag`, `--max-step` | допуск дискретизации и максимальный шаг по контуру, мм | `0.01`, `1` |
| `--no-power-comp` | не менять мощность проволоки по её длине | выкл. |
| `--power-step` | минимальное изменение S для новой команды `M03` | `5` |

Все параметры: `python FM_step2gcode.py --help`.

#### Материалы

В `materials.json` лежат режимы резки для конкретного пенопласта: `FeedRateCut` — скорость реза, мм/с; `WireMinPower` — мощность S при прямой проволоке (374 мм); `WireMaxPower` — потолок S; `Kerf` — толщина реза, мм. Свой пенопласт добавляйте по образцу существующей записи.

## Что где лежит

| Файл | Назначение |
|---|---|
| `index.html` | веб-интерфейс: генератор, 3D-просмотр, управление станком |
| `FM_step2gcode.py` | Python-генератор G-кода из STEP |
| `FM_step.py` | чтение STEP и разбор детали на линейчатые поверхности |
| `FM_lib.py` | настройки станка и блоки G-кода (старт, конец, торцевание) |
| `materials.json` | режимы резки для разных пенопластов |
| `lib/` | библиотека three.js для 3D-вида |
