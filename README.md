# Струнная резка пенопласта

**От STEP-файла до реза в одном окне**

Раньше путь от модели до станка был таким: запускаешь макросы в FreeCAD, они строят G-код, потом открываешь Candle и отправляешь его на станок. Candle сделан для обычных ЧПУ, поэтому показывает только линии траектории, а как идёт резка проволокой, не видно. Приходилось верить коду на слово.

Теперь всё в одной странице браузера.

- **Загрузили STEP, получили G-код.** Одна деталь или две из одной заготовки, одна из них зеркальная: например, левая и правая консоли крыла. Кнопка «Зеркало» делает это за вас.
- **Резка видна до запуска.** Программа открывается в 3D, и можно прогнать её на экране: смотреть вид сверху, вдоль струны или в объёме.
- **Станок управляется оттуда же.** Подключение по USB, хоминг, старт, пауза, всё на одной вкладке.
- **Ничего не нужно устанавливать.** Откройте `index.html` в Chrome или Edge. Интернет тоже не нужен: всё нужное лежит в папке.
- **Открытый код.** Можно читать, менять под свой станок и разбираться, что именно уходит в G-код.

Было: FreeCAD, макросы, Candle и угадывание траектории. Стало: один файл, понятная картинка и меньше испорченных заготовок.

---

Программа для станка с горячей струной и поворотным столом (GRBL, оси XYZAB).

> ⚠️ **Аварийная остановка — только физическим ключом или выключателем питания.** Кнопка «Стоп» на странице не является аварийной.

## Возможности

- **Вкладка «ГЕНЕРАТОР G-CODE»** строит G-код из STEP-файла:
  1. одна деталь;
  2. две детали из одной заготовки, одна из них зеркальная (например, левая и правая консоли крыла).
- **Вкладка «РЕЗКА»** показывает программу в 3D, отправляет её на станок и управляет им по USB.

## Выбор пар кривых прямо в 3D генератора

Откройте `index.html`, загрузите STEP с вспомогательными кривыми, нажмите **«Выбрать кривые в 3D»** над существующим трёхмерным окном. Далее щёлкните **две кривые** (они выделятся жёлтым) и нажмите **Enter**. Подтверждённая пара станет зелёной; можно сразу выбрать следующую пару и снова нажать Enter. Вращение модели мышкой сохраняется, движение курсора с зажатой кнопкой не выбирает кривые. **Esc** отменяет текущий выбор; **«Отменить пару»** удаляет последнюю сохранённую пару. **«Сохранить пары JSON»** выгружает назначения для STEP.

Работает поверх уже существующего Three.js вида с заготовкой и каретками. Дополнительный редактор `tools/guide-editor.html` остаётся в репозитории как экспериментальный инструмент, но для назначения пар он больше не нужен. Сохранённые пары являются только технологическими аннотациями; G-code не разблокируется до отдельной проверки безопасной обработки.

## Редактор направляющих мышкой (ранний автономный прототип)

Если автоматическое сопоставление кривых оказалось неоднозначным, откройте [`tools/guide-editor.html`](tools/guide-editor.html) в Chrome/Edge **после скачивания и распаковки архива репозитория**. Также из вкладки «ГЕНЕРАТОР G-CODE» доступна кнопка **«Назначить направляющие мышкой»**.

1. Нажмите «Открыть STEP» и выберите `F4-11.stp`.
2. Для B0 редактор автоматически выбирает **#197 и #544** — две кривые в Y-плоскостях. Для B90 выберите **#337 и #681** (X-плоскости). Соединительные линии **#694 и #707** отдельно отображаются в списке кривых, но не являются парой профилей.
3. Щёлкните точку на левом профиле, потом соответствующую на правом; повторите для других характерных точек. При необходимости переключите направление обхода B.
4. Ползунок «Проход» показывает положение прямой струны и предварительные координаты кареток. Переключение пар сохраняет ранее назначенные соответствия.
5. **«Сохранить соответствия JSON»** записывает все назначенные операции; через «Загрузить JSON» их можно восстановить.

Это функциональный прототип **интерактивного назначения направляющих**, а не полноценный CAM-постпроцессор. Сохранённый JSON ещё не подключён к генерации G-code: дальнейшая проверка проникновения струны в твёрдое тело, выбор стороны реза, безопасный вход/выход и моделирование удаления материала обязательны. В частности, интерфейс не объявляет траектории безопасными только потому, что пользователь назначил соответствия.

## F4-1: вспомогательные кривые (экспериментальный импорт)

STEP с твёрдым телом и независимым `GEOMETRIC_CURVE_SET` теперь сохраняет B-spline направляющие. В предпросмотре они показаны **розовыми линиями**. Для образца F4-1 ожидаются четыре кривые в двух парах на разных плоскостях.

Добавлен диагностический расчёт `Model.guideKinematics()`: для каждой пары предлагается B0 или B90, вычисляются согласованные координаты двух концов струны на плоскостях кареток с экстраполяцией до ширины поля станка. Оба направления используют **единое начало координат всей модели**. Результат имеет статус `diagnostic_only`, для управления станком не предназначен.

### Проверка сохранности тела для F4-1

Добавлен автономный диагностический скрипт `tools/check_step_guides.py` (зависимости: Python, NumPy, SciPy, OCP / CadQuery):

```bash
python tools/check_step_guides.py /path/to/F4-1.stp --pairs 197:406 544:681
```

Он читает B-spline из исходного STEP, пересчитывает профили по длине дуги, подбирает направление/сдвиг замкнутого контура и проверяет выбранные точки прямой струны через классификатор тела OpenCascade. Возвращает код завершения **2**, если есть хотя бы одна точка внутри сохраняемого тела. Отсутствие таких точек при дискретизации **не доказывает** безопасность всей операции.

При локальной проверке F4-1 по 288 точкам на каждую пару обнаружены проникновения в тело: **66/288 для #197/#406 и 49/288 для #544/#681** (данный результат зависит от шага и соответствия точек). Это опровергает гипотезу, что простая интерполяция обеих пар достаточна для корректной обработки. Требуется уточнить технологическое назначение кривых и разработать настоящий планировщик удаляемого объёма.

**Важно:** это пока проверка импорта, а не готовый маршрут станка. До построения согласованных парных проходов, определения поворотов стола, безопасных входов и проверки удаляемого объёма **генерация G-code для STEP с телом и вспомогательными кривыми намеренно блокируется**. Это предотвращает опасную ситуацию, когда часть геометрии незаметно игнорируется.


### Эксперимент: неравномерная синхронизация кареток

При равномерной параметризации вспомогательные прямые пересекают сохраняемое тело. Добавлен `tools/optimize_step_guides.py`: монотонное динамическое сопоставление кривых, допускающее неодинаковые скорости кареток и сдвиг начала замкнутого контура. Для ускорения поиска используется триангулированное твёрдое тело, а не точный классификатор для каждого пробного положения.

```bash
python tools/optimize_step_guides.py F4-1.stp --samples 48 --output F4_optimized.json
```

На F4-1 после более плотной независимой проверки оптимизированных кандидатов остаются точки внутри конечного тела: **13/1026 для #197/#406 и 58/969 для #544/#681**. Эти числа зависят от шага сетки. Оптимизатор **не выпускает G-code**, даже если на конечной сетке не обнаружено пересечений. Требуются непрерывная проверка поверхности реза, корректный вход/выход струны, итоговая проверка удаляемого объёма и тест с реальными размерами заготовки.

## Предварительная рабочая версия для F2 (2026-11-04)

[**Скачать проверенный снимок целиком (ZIP)**](https://github.com/viktor2024-cell/foam-wire-cutter/archive/refs/heads/preview/f2-two-direction-v0.1.zip).

1. Распакуйте **всю** папку, не один `index.html`: рядом должны остаться `generator-view.js` и `lib/`.
2. Откройте `index.html` в последнем Chrome или Edge.
3. На вкладке генератора откройте `F2-50-325-240(1).stp` (или вариант `(2)`).
4. Параметры заготовки подставятся автоматически: **вдоль струны 50 мм, поперёк 325 мм, высота 240 мм, низ Z=0, зазор 10 мм, рез 1 мм, торцевание выключено**. Перепроверьте их по реальной заготовке и станку.
5. Выберите **одну деталь** и сформируйте G-code. Сначала выполняется дополнительный контур при `B90`, затем `B0` и внешний профиль. Результат можно полностью просмотреть на вкладке «РЕЗКА» до подключения станка.
6. Если толщина исходного листа 100 мм, вручную укажите **100 мм вдоль струны** и включите торцевание: оно выполняется до выреза канала.

**Ограничения этой версии:** дополнительная геометрия должна состоять из замкнутых связанных линейчатых контуров, совместимых с горизонтальной горячей струной и поворотом стола. Сочетание таких контуров с режимами «пара» и «зеркало» пока заблокировано. Необрабатываемые поверхности вызывают ошибку, а не незаметное пропускание реза.

Встроенный симулятор проверяет границы перемещения, но **не заменяет сухой прогон на реальном станке**. Перед нагревом проволоки проверьте соответствие B-угла, направления движения, размеры заготовки, свободное пространство при вращении и физическую аварийную остановку.

## Запуск

Откройте `index.html` в браузере: установка не нужна, интернет тоже. Управление станком по USB работает только в Chrome или Edge: страница открывает COM-порт через Web Serial.

Папка `lib/` (three.js r128, лицензия MIT — `lib/three.LICENSE`) нужна для 3D-вида, держите её рядом с `index.html`.

## Что где лежит

| Файл | Назначение |
|---|---|
| `index.html` | веб-интерфейс: генератор, 3D-просмотр, управление станком |
| `FM_step2gcode.py` | Python-генератор G-кода из STEP |
| `FM_step.py` | чтение STEP и разбор детали на линейчатые поверхности |
| `FM_lib.py` | настройки станка и блоки G-кода (старт, конец, торцевание) |
| `materials.json` | режимы резки для разных пенопластов |
| `lib/` | библиотека three.js для 3D-вида |

## Размещение модели перед генерацией

В генераторе доступны 3D, вид сверху и вид сбоку вдоль струны. Голубая рамка показывает заготовку, оранжевая модель — её размещение по центру. Если модель не помещается, она отображается красным. Изменения размеров заготовки сразу обновляют просмотр.

Стрелки X/Y/Z поворачивают **модель** на ±90° вокруг осей станка: X вдоль струны, Y поперёк, Z вверх. Кнопка сброса возвращает исходную ориентацию. Масштаб задаётся в процентах и применяется равномерно ко всей модели; толщина реза и параметры станка от этого не меняются. Поворот и масштаб учитываются при генерации G-code. Размах модели должен оставаться вдоль струны: другие ориентации можно просматривать, но для генерации их нужно исправить.

Файл `generator-view.js` нужен для предпросмотра; держите его рядом с `index.html`. Это геометрическая проверка размещения. Проверка полного маршрута выполняется при генерации и в модуле резки.

Рядом с поворотом находятся кнопки смещения модели X/Y/Z на 5 мм относительно центра заготовки и кнопка «По центру». X направлена вдоль струны: смещение меняет расчёт координат обеих кареток. Изменение расположения требует заново сформировать G-code. Генератор проверяет, что модель помещается в заготовку и траектория не превышает ход станка.

Пока смещение доступно для одиночной детали без дополнительных направлений резки и без обработки STEP только с кривыми; для пары оно заблокировано. Торцевание при смещении X также заблокировано. Для F1-1 проверочный пример: поворот модели Z +90°, заготовка 100 × 145 × 135 мм, низ Z 40 мм, допуск STEP 0,6 мм, торцевание выключено, смещение X −25 мм. Конкретную заготовку и траекторию проверяйте перед резом.
