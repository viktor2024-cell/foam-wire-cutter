# Струнная резка пенопласта

Программа для станка с горячей струной и поворотным столом (GRBL, оси XYZAB).

**Вкладка «ГЕНЕРАТОР GCODE»** строит G-code из STEP: одна деталь, зеркальная половина или пара деталей в одной заготовке.

**Вкладка «РЕЗКА»** показывает программу в 3D, проверяет её и управляет станком по USB.

Управление станком работает в Chrome или Edge: страница открывает COM-порт через Web Serial.

`index.html` работает без установки. Файлы `FM_*.py` и `materials.json` дают резервный генератор на Python:

```bash
python FM_step2gcode.py деталь.stp --stock 340 230 50 --bottom-z 10
```

Аварийно останавливайте станок физической кнопкой или выключателем питания: «Стоп» на странице программный.
